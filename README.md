# Прогнозирование уровня нарциссизма по текстовым данным

## Цель исследования

Разработать и сравнить модели машинного обучения для автоматического определения уровня здорового нарциссизма (низкий, средний, высокий) на основе текстовых ответов респондентов на русском языке.

В работе используются два подхода к векторизации текста:
- **TF-IDF** — частотный метод,
- **BGE-M3** — контекстуальные эмбеддинги (SentenceTransformer).

На их основе обучаются шесть классификационных моделей: логистическая регрессия, дерево решений, случайный лес, SVM, XGBoost и LightGBM.

## Структура репозитория

| Файл | Описание |
|------|----------|
| `narcissism_statistics.ipynb` | Предобработка данных, бинаризация ответов NPI-40, расчёт баллов, статистический анализ (распределение классов, тест Шапиро‑Уилка, критерий Краскела‑Уоллиса, корреляция Спирмена, TF‑IDF анализ текстовых блоков). |
| `narcissism_ml.ipynb` | Векторизация текстов (TF-IDF и эмбеддинги BGE-M3), обучение шести моделей с подбором гиперпараметров (RandomizedSearchCV), оценка на тестовой выборке, визуализация сравнения F1‑score. |
| `data/data.csv` | Итоговый датасет после статистической обработки (сохраняется при запуске первого ноутбука). |

## Основные результаты

### Лучшие комбинации «векторизатор + модель»

| Векторизация | Модель | Общий F1‑score | F1 (низкий) | F1 (средний) | F1 (высокий) |
|--------------|--------|----------------|--------------|---------------|----------------|
| TF‑IDF | XGBoost | **0.5676** | 0.5000 | 0.7073 | 0.1667 |
| Эмбеддинги BGE‑M3 | Логистическая регрессия | **0.4912** | 0.3429 | 0.6000 | **0.3810** |

### Ключевые выводы

1. **XGBoost + TF‑IDF** даёт максимальный общий F1, но почти не распознаёт высокий уровень нарциссизма.
2. **Логистическая регрессия + эмбеддинги BGE‑M3** обеспечивает наиболее сбалансированное качество по всем трём классам и лучший F1 для высокого уровня (0.381).
3. Переход к эмбеддингам снижает переобучение и позволяет линейным моделям использовать плотные семантические признаки.
4. Главные ограничения — малый размер выборки (313 наблюдений) и сильный дисбаланс классов (особенно мало примеров высокого уровня нарциссизма).
